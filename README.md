<h1 align="center">🌐 DSUMUN Website</h1>
    <p align="center"><img src="https://github.com/ArjiJethin/DSUMUN/blob/main/public/MUNSOCLOGO2-white.png?raw=true" alt="DSUMUN Logo" height="250" /></p>
    <h2>Description 📜</h2>
    <p> <strong>DSUMUN Website</strong> is the official digital platform for the Dayananda Sagar University Model United
        Nations Society. Built with React, this modern, responsive website serves as a hub for information, event
        updates, delegate registrations, and showcasing the spirit of diplomacy and debate that DSUMUN is known for.
    </p>
    <h2>Features 💡</h2>
    <ul>
        <li><strong>Home Page:</strong> Dynamic landing section with society highlights and call-to-actions.</li>
        <li><strong>About Us:</strong> A detailed overview of DSUMUN’s mission, vision, and legacy.</li>
        <li><strong>Committees:</strong> Interactive pages for each committee with agendas and background guides.</li>
        <li><strong>Team:</strong> Meet the Executive Board and Organizing Committee.</li>
        <li><strong>Registration:</strong> Smooth delegate and college delegation registration system.</li>
        <li><strong>Gallery:</strong> High-quality event snapshots from previous editions.</li>
        <li><strong>Contact:</strong> Integrated form and contact details with Google Maps support.</li>
        <li><strong>Responsive Design:</strong> Optimized for desktops, tablets, and mobiles.</li>
    </ul>
    <h2>Getting Started 🚀</h2>
    <h3>Prerequisites</h3>
    <ul>
        <li>Node.js (v16 or above)</li>
        <li>npm or yarn</li>
        <li>IDE: Visual Studio Code recommended</li>
    </ul>
    <h3>Installation 💾</h3>
    <ol>
        <li>Clone the repository:</li>
        <pre><code>git clone https://github.com/your-username/DSUMUN.git</code></pre>
        <li>Navigate to the project directory:</li>
        <pre><code>cd DSUMUN</code></pre>
        <li>Install dependencies:</li>
        <pre><code>npm install</code></pre>
        <li>Start the development server:</li>
        <pre><code>npm start</code></pre>
    </ol>
    <h2>Usage 🛠️</h2>
    <ol>
        <li>Explore the homepage and navigate to various sections.</li>
        <li>Use the registration form to sign up for upcoming conferences.</li>
        <li>View details about committees and agendas.</li>
        <li>Check out the gallery and meet the team behind DSUMUN.</li>
    </ol>
